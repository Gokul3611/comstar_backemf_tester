# Back-EMF Motor Tester

An industrial automated testing system designed to measure and analyse the Back Electromotive Force (Back-EMF) generated by an electric motor during a controlled test cycle.

The system integrates PLC-based motion control, VFD communication, pneumatic actuation, safety interlocks, and real-time voltage acquisition to automate motor testing.

## Overview

The Back-EMF Tester automates the process of coupling a motor, controlling its speed, executing a test cycle, and capturing electrical measurements.

The PLC manages the complete machine sequence while monitoring safety conditions, actuator feedback, and VFD telemetry.

## Key Features

- **Automated Test Sequence:** State-machine-based control for initialization, clamping, sled positioning, testing, and teardown.
- **Motor Speed Control:** VFD integration for controlled motor operation.
- **Back-EMF Acquisition:** Real-time motor voltage measurement with peak and average voltage calculations.
- **Pneumatic Actuation:** Independent clamp and sled cylinder control with position feedback.
- **Safety Monitoring:** E-stop, door interlock, and pneumatic pressure monitoring.
- **Fault Management:** Latched fault handling with fault identification and reset logic.
- **HMI Integration:** PLC-HMI communication for test parameters, machine status, and telemetry.
- **VFD Telemetry:** Monitoring of actual frequency, motor RPM, current, and drive fault codes.

## System Architecture

The system is organised into the following functional layers:

| Layer | Responsibility |
|---|---|
| PLC Control | Machine sequencing and supervisory logic |
| Motion Control | Clamp and sled pneumatic actuation |
| VFD Interface | Motor speed and drive control |
| Data Acquisition | Motor voltage measurement and statistical processing |
| Safety System | Interlock monitoring and fault handling |
| HMI | Operator commands, configuration, and monitoring |

## Machine State Sequence

The machine operates through a defined finite-state machine.

| State | Description |
|---|---|
| `INIT` | Initialize and home actuators |
| `IDLE` | Wait for operator start |
| `WAIT_CLAMP` | Engage motor clamp |
| `WAIT_MOVE` | Extend sled towards the DUT |
| `TEST_READY` | Verify VFD readiness |
| `TESTING` | Execute Back-EMF test |
| `TEARDOWN` | Decelerate motor and retract sled |
| `WAIT_UNCLAMP` | Release motor clamp |
| `FAULT` | Enter safe-stop fault state |

## Safety and Fault Management

The system implements dedicated safety and actuator supervision logic.

Safety interlocks include:
- Emergency stop monitoring.
- Door interlock monitoring.
- Pneumatic pressure monitoring.
- Latched safety faults requiring reset.

Actuator supervision includes:
- Cylinder extension and retraction timeout detection.
- Position sensor conflict detection.
- First-fault capture.
- Solenoid outputs disabled during latched faults.

### Fault Classification

| Fault Code | Description |
|---|---|
| `10` | Emergency stop |
| `20` | Air pressure loss |
| `25` | Door open |
| `30` | Clamp timeout |
| `40` | Sled forward timeout |
| `50` | Sled reverse timeout |
| `60` | Sensor conflict |
| `70` | Command conflict |
| `80` | Watchdog timeout |
| `90` | Invalid state |
| `100` | VFD not ready |
| `110` | VFD fault |

## PLC-HMI Communication

The PLC exposes a Modbus register interface for operator commands, machine status, test parameters, acquisition results, and VFD telemetry.

### HMI to PLC

| Register | Parameter |
|---|---|
| MW1 | Test speed (RPM) |
| MW2 | Acceleration time |
| MW3 | Deceleration time |
| MW4 | Manual command bitfield |
| MW5 | Test duration |
| MW6 | HMI heartbeat |

### PLC to HMI

| Register | Parameter |
|---|---|
| MW10 | Machine state |
| MW11 | Active fault |
| MW12 | System health |
| MW13 | HMI communication fault |
| MW20–MW23 | Cycle count and runtime |
| MW30–MW32 | Motor voltage statistics |
| MW40–MW46 | VFD telemetry and status |

## Data Acquisition

The acquisition subsystem handles motor voltage measurement and test-window analytics.

Tracked parameters include:

- Live motor terminal voltage.
- Peak motor voltage.
- Average motor voltage.
- Number of acquisition samples.
- Transducer current.

Voltage statistics are maintained over the active test window.

## Technology Stack

- **PLC Programming:** IEC 61131-3 Structured Text
- **Control Architecture:** Finite State Machine
- **Actuator Control:** Pneumatic cylinders and solenoid valves
- **Motor Control:** Variable Frequency Drive (VFD)
- **Communication:** Modbus register-based PLC-HMI interface
- **Data Acquisition:** Analog input processing and voltage analytics
